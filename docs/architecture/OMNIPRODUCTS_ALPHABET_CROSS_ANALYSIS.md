# The 30 × OmniProducts — Cross Analysis

A real, reasoned first pass — not a mechanical lookup, and not
final. Each letter is matched to whichever real product's actual
function embodies it most directly, using the confirmed pattern
Omni(x). Where more than one product genuinely fits, or nothing
fits well yet, that's stated plainly rather than forced.

## Confirmed already, before this pass

- **Desire = Intent.** OmniValue's forward-declared intent layer.
- **PrimaryForce = Purpose.** OmniValue's backward-proven outcome layer.
- **Value.** OmniValue itself — the letter's own root product.
- **Vector.** Not one product — a real, load-bearing primitive
  (`THREE.Vector3`) running underneath OmniTargeting, OmniGrab,
  ChronosRealityNode, and elsewhere. Kept as infrastructure, not
  assigned to a single product.

## What this leaves genuinely open

- **Four real double-uses**: OmniPlayer (Attract/Progression/Energy —
  three, not two), OmniBrowserSpace (Internal/External), OmniValue
  (PrimaryForce/Desire/Value/Conflict — four), OmniCell (Variable/
  Data). Not necessarily a problem — a rich product plausibly
  embodies more than one axiom — but worth a real decision on
  whether that's the intended shape or whether some of these should
  be pulled apart into named sub-products instead.
- **OmniAction and OmniTruths** are matched to letters (Operate, End)
  while still being mostly conceptual/undocumented themselves — the
  match is more "this is clearly what the name is for" than "this is
  a proven, tested product," unlike most of the rest of this table.
- **No product currently claims**: nothing distinct was found for
  Begin beyond OmniLandingRoom, which is a stretch (a landing room is
  *a* beginning, not necessarily *the* concept of beginning itself).
  Worth flagging as the weakest single match in the table.
- This is still a proposal, the same way the original 44→30
  reduction was — offered for your correction, not treated as final.
