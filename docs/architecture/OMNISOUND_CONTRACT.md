# OmniSound CONTRACT (V194) — shared by the three builders. Do not deviate from names/signatures; add, never rename.

Goal (owner): a SoundNode that DIMENSIONALIZES a note / sound: as many settings as possible (sustained sound, FX, playback variables like iterative play and looping, dynamics ppp..ffff, crescendo, ...). The node has TWO systems: (1) its GEOMETRY (the node mesh, which reacts to the sound) and (2) PARTICLES whose count / formation / movement come from the sound's FREQUENCY content. Extra VIEWERS show the frequency and the particle formation. Every ordinary node can also carry sound.

## Data on a node (persisted by reference with the node, like other kinds)
- `node.data.nodeKind = 'soundNode'` for a SoundNode (kind id constant `KIND_SOUND = 'soundNode'`).
- `node.data.sound`          : object from `sanitizeSound()` (agent 1's model). On ordinary nodes it exists only if the user enabled sound; `sound.enabled` (bool) says whether the node makes sound at all. A SoundNode defaults to enabled = true.
- `node.data.soundParticles` : object from `sanitizeParticles()` (agent 3's model). Only meaningful for nodes with sound enabled.

## utils/OmniSoundModel.js  (AGENT 1 owns) — pure, no DOM, no Web Audio
- `SOUND_SCHEMA`: array of groups `{ id, label, desc, fields: [{ key, label, type: 'number'|'enum'|'bool'|'note'|'text'|'color', min, max, step, unit, options:[{value,label}], default, desc }] }`. UI code (agent 2) generates controls ONLY from this schema, so every setting must be described here. Field keys are flat keys of the `sound` object.
- `defaultSound()`, `sanitizeSound(raw)` (complete valid object, clamps numbers, enums fall back, never throws, ignores unknown keys, safe on hostile input like __proto__), `SOUND_LIMITS`, `SOUND_PRESETS` = `{ id: { label, settings:{...partial} } }` (at least 12 presets: pure sine pad, pluck, bell, organ, kick-ish, snare-ish noise burst, bass, siren, wind, drone, arp, swell...).
- `DYNAMICS` = ['pppp','ppp','pp','p','mp','mf','f','ff','fff','ffff'] and `dynamicToGain(name)` (monotonic, pppp quiet ~ 0.03, ffff = 1.0), `noteToFreq(name|midiNumber, a4=440)`, `freqToNote(freq)`, `midiToFreq`, `NOTE_NAMES`.
- Must cover (the owner wants nearly every setting): SOURCE (oscillator waveform sine/square/saw/triangle/custom partials, noise white/pink/brown, sample from uploaded audio, additive harmonics count + rolloff, FM ratio/depth, pulse width, unison voices + detune spread, sub oscillator), PITCH (note name, octave, midi, fine tune cents, transpose, glide/portamento, vibrato rate/depth/delay, pitch envelope), AMPLITUDE (dynamic mark ppp..ffff + free gain dB, ADSR attack/decay/sustain level/release with curve shapes, SUSTAINED mode: hold indefinitely until stopped, duration, tremolo rate/depth/shape, crescendo / decrescendo: from-dynamic to-dynamic over N seconds with curve), TIME / PLAYBACK (loop on/off, loop count / infinite, ITERATIVE play: repeat count, interval ms, interval jitter, pitch step per iteration (arpeggio / ladder), gain step per iteration, playback rate for samples, start offset, reverse for samples, retrigger vs legato, auto-start on scene load / on proximity / on click / manual, trigger on node events), FILTER (type lowpass/highpass/bandpass/notch/peaking/shelves, cutoff, Q, gain, filter envelope amount, LFO on cutoff), FX (reverb: size/decay/dry-wet; delay: time/feedback/mix; distortion: amount/type; chorus or flanger: rate/depth/mix; bitcrush bits; compressor threshold/ratio; 3-band EQ low/mid/high; stereo width), SPATIAL (positional on/off, distance model, refDistance, maxDistance, rolloff, cone inner/outer angle, pan, doppler off/on, occlusion none), ANALYSIS (fftSize 256..4096, smoothing 0..0.99, min/max dB), META (label, tags, color).

## systems/OmniSoundEngine.js  (AGENT 1 owns) — Web Audio, singleton default export `SoundEngine` (also named exports)
- `SoundEngine.unlock()` resumes the AudioContext (it also auto-installs one-time pointerdown/keydown listeners); `isUnlocked()`; emits window event `omni:sound-unlock-needed` when something wants to play while locked.
- `SoundEngine.start(nodeId, sound, ctx?)` builds a voice graph from a sanitized `sound` (ctx = `{ getWorldPosition: () => THREE.Vector3|{x,y,z} }`), `update(nodeId, sound)` applies changed settings live without clicks (use setTargetAtTime), `stop(nodeId, {immediate})` (release stage unless immediate), `stopAll()`, `isPlaying(nodeId)`, `playing()` → ids, voice cap (default 8, oldest stolen, setting), `setMasterVolume(v)`, `getMasterVolume()`, `setMuted(b)`.
- `SoundEngine.getAnalysis(nodeId)` → `null` or `{ nodeId, playing, phase:'attack'|'decay'|'sustain'|'release'|'idle', level:0..1, bands:{sub,bass,lowMid,mid,highMid,presence,brilliance}, peakHz, spectrum:Uint8Array, waveform:Uint8Array, binCount, sampleRate, iteration, loopCount, dynamicNow:string }`; typed arrays are reused between calls (do not retain). `SoundEngine.getMasterAnalysis()` same shape for the whole mix (nodeId 'master'); bridge to the existing OmniMixer if it has an analyser (look at ui/OmniMixerPanel.js, docs/omniproducts/MUSIC_REACTIVE_PANELS_DESIGN.md) so the mixer's output is also available as 'master' / 'mixer'.
- Events on window: `omni:sound-state` `{nodeId, state:'started'|'stopped'|'looped'|'iteration'|'phase', phase?, iteration?}`.
- Offline/jsdom friendliness: when `AudioContext` is missing (tests) the engine must degrade to a deterministic no-audio fake with the same API and synthetic analysis (so tests can run), exposing `SoundEngine._fake = true`.
## systems/OmniSoundScene.js  (AGENT 1 owns) — module `{init, update(delta), destroy}` constructor `(context, omniNode)`: each frame sets the audio listener from the camera (position + orientation) and node positions (positional sound, distance attenuation done by the engine's PannerNode), auto-start rules (`autoStart`: 'manual'|'scene-load'|'proximity'|'click'), drives iteration / loop / crescendo scheduling if not done inside the engine, stops voices of deleted nodes (`omni:node-deleted {id}`), listens to `omni:sound-play-request {nodeId}` / `omni:sound-stop-request {nodeId}` / `omni:sound-toggle-request {nodeId}`. Admin-level global settings (master volume, voice cap, mute on phone, autoplay opt-in) are in `utils/OmniSoundSettings.js` (AGENT 2 owns, key `omni:sound-settings-v1`, event `omni:sound-settings-set`, getters `getSoundSettings()`); the engine/scene read it defensively (guard if the module is missing).

## utils/OmniSoundParticleModel.js  (AGENT 3 owns) — pure
- `PARTICLE_SCHEMA` (same shape as SOUND_SCHEMA), `defaultParticles()`, `sanitizeParticles(raw)`, `PARTICLE_LIMITS` (per-node count cap 4000 default max, global cap 20000), `FORMATIONS` list, `bandToMotion` defaults. Fields at least: enabled, particle COUNT (0..4000), formation (ring, sphere shell, spiral, helix, galaxy, lissajous, wave sheet, bars (spectrum columns), cube lattice, burst), size, size-by-level, colour mode (solid / by band / by pitch hue / gradient) + colours, opacity, blend (normal/additive), spread radius, movement mapping: for each of the 7 bands a target (radius, height, swirl, jitter, size, brightness, none) and a gain, smoothing, attack/release of the motion, rotation speed, noise amount, trail / fade, respond-only-while-playing toggle, LOD (reduce count by distance).
## systems/OmniSoundParticles.js (AGENT 3 owns) — module `{init, update(delta), destroy}` constructor `(context, omniNode)`: for every node whose `data.sound.enabled` and `data.soundParticles.enabled` creates ONE `THREE.Points` (BufferGeometry, positions updated on the CPU or a vertex shader driven by a uniform array of 7 band values; no new WebGL context; use the existing scene) attached at the node's position, driven by `SoundEngine.getAnalysis(nodeId)`; dispose geometry/material when the node is deleted or disabled; global particle cap; pause when the node is far/offscreen or silent; fall back gracefully when `SoundEngine` or analysis is missing.
## Viewers (AGENT 3 owns) — class-A window panels (utils/OmniWindowChrome.js), 2D canvas only:
- `ui/OmniSoundViewerPanel.js` (⟐SoundViewer): frequency viewer for the selected sound node (or master): spectrum bars, log-frequency line, waveform scope, scrolling spectrogram, 7 band meters, peak Hz + note name, dB scale, pause/freeze, FFT zoom, node picker, ADSR phase indicator.
- `ui/OmniSoundParticleViewerPanel.js` (⟐SoundParticleViewer): particle FORMATION viewer: a 2D canvas projection (rotatable top/front/side) of the current formation with live particle count, per-band activity overlay, the formation picker and count / size sliders that edit `data.soundParticles` of the selected node live.
- both registered in the ribbon in a NEW group captioned 'Sound' inside the Home tab (add it after the 'Windows' group; AGENT 2 adds the SoundNode create button in the 'Create' group and the SoundNode panel button in 'Tools'), openable via events `omni:nav-select` items '⟐SoundViewer' / '⟐SoundParticleViewer'.
