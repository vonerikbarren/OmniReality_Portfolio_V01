# The 30 — Reclassified from the 44-Entry Legacy List

A real proposal, not a final decision — offered for correction, the
same way the legacy list itself was already run through this process
once with Copilot and not recovered. ⟐ is excluded from the 30
itself: it's confirmed as the Omni(x) prefix/operator applied to all
30, not one of the 30 values x can take. Δ (Change) is kept as a real,
standalone root — the temporal opening, paired conceptually with
Ω (End) as the closing.

**Method**: an intensity-escalation of the same axiom (the Fire →
Fira → Firaga pattern already used elsewhere in this project) merges
into the root letter as a tier. A directional polarity — genuinely
opposite, not just "more of the same axiom" — stays as two separate
letters. Two legacy entries shared a single glyph in the original
table (⟐ for both Objectivity/CoreOfChange; ◬ш for both Progression/
Subjugation) — both real signals a merge was already half-sensed.

## What this leaves genuinely open

- This is one real, defensible reduction — not the only one possible.
  Vector and Value were both deliberately protected from being merged
  away because of their real weight elsewhere in this project, which
  is a judgment call, not a neutral rule.
- ~~Purpose/Intent — isn't obviously present under an exact matching
  name~~ — confirmed directly: **PrimaryForce() is Purpose. Desire()
  is Intent.** Both already survive in the 30, unmerged — this
  retroactively sharpens the whole intent-verification system in
  `OMNIVALUE_DESIGN.md`: the backward-derived, outcome-proven layer
  (PrimaryForce) is literally Purpose being read out of what actually
  happened; the forward, low-weight, direction-only declaration
  (Desire) is literally Intent, exactly as aspirational and unproven
  as "what someone wants" should be.
- The *order* of the original 44 may itself have been a genesis
  sequence (what had to exist before the next thing could) rather
  than incidental — this reclassification preserved rough position
  but did not attempt to re-derive or verify that causal ordering.
