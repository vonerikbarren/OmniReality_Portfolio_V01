# ⟐mniMenu Drawer × The 30 — Meaning-Comparison Mapping

A real, reasoned first pass matching every entry currently in
`ui/Drawer.js`'s `LEFT_ITEMS` (the ⟐mniMenu drawer — see item 37 in
`DeveloperQueue.md`) to whichever of The 30 (`THE_30_RECLASSIFICATION.md`)
fits it by meaning. Not the same table as
`OMNIPRODUCTS_ALPHABET_CROSS_ANALYSIS.md` — that one matches *products*
(some not even in this drawer, like OmniValue/OmniCell/OmniStory) to
letters. This one matches *menu entries* specifically, so it surfaces a
different, real finding: how badly overloaded some letters get once
you count every drawer item pointing at roughly the same idea, and
which drawer entries don't cleanly match anything yet.

## What this leaves genuinely open

- **Operate is doing five jobs** (OmniTargeting, OmniKeys, PanelControl,
  OmniNavi, Admin, Governance — six, actually, once Governance is
  counted): control input, panel management, autonomous programs,
  system administration, and rule-setting are all landing on one
  letter. Either Operate genuinely is that broad a root concept in
  this system, or some of these want to be pulled apart — the same
  open question the product cross-analysis already raised about
  OmniValue/OmniPlayer being overloaded, just showing up again here
  at the menu level.
- **Three real gaps, not forced**: ⟐OmniEXP, ⟐Experiences, and
  ⟐Intelligence don't cleanly match any of the 30 as currently named.
  Intelligence in particular is worth raising back against
  `THE_30_RECLASSIFICATION.md` itself — it may be a real concept that
  list is missing, not a matching failure on this pass.
- **⟐OmniVision vs. ⟐OmniVisor** is the one real, pre-existing naming
  question this pass surfaced concretely again — both plausibly claim
  Perspective/Illuminate and neither is clearly wrong. Worth an actual
  decision.
- **Likely redundant pairs**: ⟐OmniRealities/⟐Realities and
  ⟐OmniChronos/⟐Times land on the same letter for the same reason —
  worth asking whether the category-block entries are meant to be
  something genuinely different from their app-launcher counterparts,
  or are leftover duplication from before the menu had two blocks.
