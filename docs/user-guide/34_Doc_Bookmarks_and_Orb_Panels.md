# Doc bookmarks and quiet orb panels (V237)

## Bookmarks in ⟐OmniDoc
- Each document (a PDF, a guide page, any source) keeps up to **20 bookmarks**. They belong to the document, so the same PDF shows the same bookmarks in every doc node, and they are remembered in this browser.
- **＋ Bookmark page N** saves the page you are on. A page can only be bookmarked once. The 21st bookmark is refused with a message; delete one first.
- Click the **p. N** button to go to that page. Click the **title** to rename it (Enter or click away to save). **×** deletes it.

## Orb panels no longer print instructions
The text at the bottom of each hand's orb (hints such as "Click words to choose them…") is hidden. The same text still appears in the small **OmniNotifyOfHands** circle beside the hand, which is where it belongs (⟐OmniHands → ⦿ Orb-it → "Notify circle" to show or hide that circle).
