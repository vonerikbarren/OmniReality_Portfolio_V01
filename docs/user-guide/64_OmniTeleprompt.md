# OmniTeleprompt

A panel that comes up from the bottom of the screen and tells you something. Open it with the ▭ button in the ribbon (OmniStar group). Esc closes it.

The gear sets: edge (bottom, left or top), size, text size, opacity, scroll speed, how many seconds before it hides itself, and dark.

Commands:
- `Omni Teleprompt show text(Hello) title(Welcome) edge(left) seconds(8)`
- `Omni Teleprompt hide`
- `Omni Teleprompt set edge(top) size(200) dark(true)`

Text is shown as plain text. Settings stay in this browser.
