# 44 · Ribbon: Walk and Pages

[Guide index](README.md)

The **Sandbox** tab now has two groups so you do not have to type commands:

- **Lineup** — *Walk lineup* starts a camera walk along the first lineup (tap again or press Esc to stop); *Prev stop* / *Next stop* move during a walk.
- **Pages** — *Pages back* / *Pages forward* flip the newest doc window one page.

If there is no lineup or doc window yet, a note tells you the command that makes one (`Omni Lineup create`, `Omni Doc window`).

## Keys (V252)

| Keys | What it does |
|---|---|
| Alt+W | Start walking the first lineup / stop |
| Alt+, and Alt+. | Previous stop / next stop during a walk |
| Alt+[ and Alt+] | Flip the newest doc window back / forward one page |

They do nothing while you are typing in a text box. They are also listed in the Keyboard Shortcuts panel.
